# [农活指南] - 爽玩辅助

本篇聚焦BP、对线以及团战支援, 这其实是通用的套路公式。

::: tip
BP 指的是 Ban(禁用)和 Pick(选取)，也就是点击进入游戏后双方 禁用 和 选取英雄的阶段。
:::

## BP

鉴于游戏环境问题， BP 其实没有很大必要论述。 因为排位路人局队友基本上都是会叫辅助位置先上， 而队友自己却等对面上摇摆或者怕克制。 巅峰赛则好点， 队友基本上都会预选自己绝活， 那么这个情况就可以进行BP上的博弈。

那么 BP 阶段我们需要思考什么呢?
