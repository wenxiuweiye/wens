## 📖 知识

### 1. 营销类网站的 特效类 UI 组件库

- [Aceternity UI](https://ui.aceternity.com/)

基于 React + tailwindcss + shadcn cli 的组件库，提供了很多营销类的组件，free 版本的订阅也能使用所有的组件。

- [Magic UI](https://magicui.design/)

与 Aceternity UI 类似，也是基于 React + tailwindcss + shadcn cli 的组件库，二者可以互补使用。Magic UI 有官方的 mcp 服务器，可以让类cursor IDE 生成更准确的代码。
